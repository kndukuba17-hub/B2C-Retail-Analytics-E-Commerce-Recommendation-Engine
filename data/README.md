# Data

**Target dataset (real-data upgrade):** [UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii) — ~1M real transactions.

Download `online_retail_II.xlsx`, place it here, and re-run the notebook to build the user-item matrix from real purchases. The committed notebook currently uses synthetic transactions (see repo README roadmap). Raw data is git-ignored.
